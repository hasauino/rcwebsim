Input probe

Shows exactly what the browser reads from a gamepad or a USB transmitter on a sim cable, so a radio can be checked before it flies the sim.

  1. Switch the radio on, then plug in the cable. Move a stick so the browser shows it.
  2. Move each stick and switch in turn and note which axis moves, which way, and how far.
  3. With the sticks centred, click a trim a few times: if the axis moves, the radio's trims reach the sim. Try it again in the radio's Student (trainer) mode if it has one.
  4. Copy the report and attach it to the issue.

No gamepad yet: plug one in and move a stick or press a button.
